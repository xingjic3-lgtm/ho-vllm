# 环境配置

本项目使用 Python + PyTorch 实现 Qwen3 推理，运行环境需要支持 NVIDIA GPU 和 CUDA。

## 1. 基础环境

推荐环境：

```text
Linux / WSL2
Python 3.10+
NVIDIA GPU
CUDA 12.x
```

先确认 GPU 和驱动正常：

```bash
nvidia-smi
```

能够看到 GPU 型号、Driver Version 和 CUDA Version，说明 NVIDIA 驱动已经正常工作。

---

## 2. 创建 Python 虚拟环境

在项目外创建独立虚拟环境：

```bash
python -m venv .venv
```

激活：

```bash
source .venv/bin/activate
```

Windows PowerShell：

```powershell
.venv\Scripts\Activate.ps1
```

确认当前 Python：

```bash
which python
python --version
```

Windows：

```powershell
where python
python --version
```

---

## 3. 安装 PyTorch

先安装支持 CUDA 的 PyTorch。

例如 CUDA 12.8：

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu128
```

安装后检查：

```bash
python -c "import torch; print(torch.__version__); print(torch.version.cuda); print(torch.cuda.is_available())"
```

正常情况下应看到：

```text
PyTorch 版本
CUDA 版本
True
```

再确认 GPU：

```bash
python -c "import torch; print(torch.cuda.get_device_name(0))"
```

---

## 4. 安装项目依赖

项目当前主要依赖：

```bash
pip install transformers safetensors
```

主要用途：

```text
torch
→ Tensor、模型结构、CUDA 推理

transformers
→ Tokenizer 和 HuggingFace 参考模型

safetensors
→ 读取 Qwen3 checkpoint
```

如果后续需要固定环境，可以导出：

```bash
pip freeze > requirements.txt
```

重新安装：

```bash
pip install -r requirements.txt
```

---

## 5. 准备 Qwen3-0.6B 模型

项目不会自动从网络下载模型，使用本地模型目录。

模型目录至少应包含：

```text
Qwen3-0.6B/
├── config.json
├── tokenizer.json
├── tokenizer_config.json
├── model.safetensors
└── ...
```

代码中的：

```python
model_path = "/path/to/Qwen3-0.6B"
```

需要修改成实际模型路径。

例如：

```python
model_path = "/root/huggingface/Qwen3-0.6B"
```

项目读取：

```text
config.json
```

建立模型结构，再从：

```text
model.safetensors
```

加载权重。

---

## 6. 检查模型 dtype

模型 dtype 从 `config.json` 中读取：

```python
dtype = getattr(
    torch,
    config.get("dtype") or config["torch_dtype"]
)
```

常见情况：

```text
float16
bfloat16
```

GPU 必须支持对应 dtype。

可以检查：

```bash
python -c "import torch; print(torch.cuda.get_device_capability())"
```

## 7. 项目运行方式

从仓库根目录运行 Python module，不建议直接进入文件目录执行单个脚本。

基础生成：

```bash
python -m learn_vllm.run
```

模型正确性测试：

```bash
python -m learn_vllm.bench.evaluation
```

性能测试：

```bash
python -m learn_vllm.bench.bench_generate
```

这样 Python 才能正确找到：

```text
learn_vllm
```

包中的其他模块。

---

## 8. CUDA 可用性检查

开始运行模型前可以执行：

```python
import torch

print("PyTorch:", torch.__version__)
print("CUDA:", torch.version.cuda)
print("CUDA available:", torch.cuda.is_available())

if torch.cuda.is_available():
    print("GPU:", torch.cuda.get_device_name(0))
```

预期：

```text
CUDA available: True
GPU: NVIDIA ...
```

如果：

```text
CUDA available: False
```

先解决 PyTorch、CUDA 或 NVIDIA Driver 环境问题，再运行模型。

---

## 9. 最小环境检查

完整环境配置完成后，可以依次确认：

```bash
python --version
nvidia-smi
```

然后：

```bash
python -c "import torch; print(torch.cuda.is_available())"
python -c "import transformers; print(transformers.__version__)"
python -c "import safetensors; print(safetensors.__version__)"
```

最后运行：

```bash
python -m learn_vllm.run
```

如果模型能够成功加载并生成文本，说明基础推理环境已经配置完成。
